# Zeitstrahl

Ein Zeitstrahl für den Unterricht: Ereignisse sammeln, mit Bildern und Notizen versehen, mit der Klasse durchscrollen und präsentieren.

Autor: eho. Die Versionsnummer steht im Menü «⋯» ganz unten.

## Ausprobieren

Seite öffnen und auf **«Beispiel ansehen»** klicken: eine Wirtschaftsgeschichte von 10 000 v. Chr. bis heute. Dabei wird nichts gespeichert.

## Selber arbeiten

- **Am Computer mit Google Chrome oder Microsoft Edge:** «Zeitstrahl-Ordner öffnen». Alles wird automatisch in einem Ordner auf deinem Computer gespeichert, ganz ohne Internet.
- **Mit Safari, Firefox und auf dem iPad:** «Neuer Zeitstrahl» oder «Zip-Datei öffnen». Gespeichert wird von Hand mit «Sichern» als Zip-Datei (auf dem iPad über das Teilen-Menü, z.B. in Dateien, OneDrive oder Teams).

## Datenschutz

Die Seite sendet keine Daten ins Internet. Deine Zeitstrahlen bleiben auf deinem Gerät, als Ordner oder als Zip-Datei. Der Browser speichert nur Einstellungen und einen Entwurf zwischen.
